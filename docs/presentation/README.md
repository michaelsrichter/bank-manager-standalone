# Presentation

**Not used yet.** This folder is filled in only if you ask Copilot to build the
presentation experience with
[`eps-demo-presentation`](../../.github/skills/eps-demo-presentation/SKILL.md).
That skill is opt-in: it is never part of bootstrap, and a demo without it is
not missing anything.

When you ask for it, usually after the demo is live and verified, this folder
explains:

- the talks (for example, a lightning talk and a one-hour session), with links
  to their slides and printable presenter scripts;
- how to present on one screen, and with two screens (a presenter console that
  drives a toolbar-free Demo Window);
- the keyboard keys, and how a wireless clicker works;
- presenter and event details, including the presenter's own QR code, and why
  they stay in the browser;
- how the demo QR code is built locally, with no outside service;
- how to edit the decks and their timing; and
- the sources and research date for every fact the talks state.
